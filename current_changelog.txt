- Changing the default sort field, sort order or search mode in Preferences now applies to the document list right away, instead of only after a restart
- Document notes and file metadata are cached when viewed, so they remain available offline
- Recover the correct API version after launching while the server is unreachable, instead of staying stuck on the minimum version
- New "Offline browsing" setting: choose "Entire library" to keep every saved view and your full document list available offline, downloaded in the background over Wi-Fi
- New "Offline & Sync" settings screen showing sync status and how much data the app has transferred
- Documents that belong to a list but aren't downloaded yet appear as placeholder rows instead of being missing
- A saved view that can't be downloaded for offline use no longer blocks the rest of the offline sync; the Offline & Sync screen now lists any views that failed to sync
- Opening a document while the server is unreachable no longer removes it from your document list
