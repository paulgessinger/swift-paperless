- Title and content search now uses the new search API on Paperless-ngx v3.0 and later, instead of the parameter that server deprecated. Older servers are unaffected.
- Fixed uploaded documents being saved with an extra 2 bytes (CRLF), which caused checksum mismatches and failed deduplication in Paperless-ngx
- Fix the "What's New" screen failing to load when a release was published without release notes
- Sharing a document link now shares the web interface URL, which opens in a browser, instead of the API URL that did not
- Fix saved views failing to load when a filter rule has a null value (e.g. a "does not have tag" rule)
- Pulling to refresh on a document now also refreshes permissions, so a permission change on the server takes effect without restarting the app
- The tip jar is back in Settings
- Fix the app picking the wrong API version when the server rejects the initial version check, for example after a login has expired
- On iPhone Duo's inner display, the document list now sits beside the open document, and the list and document stay put when you fold or unfold the phone
- The app now rotates to landscape on iPhone Duo's outer display
- Fix PDF pages and the filter bar sitting under the side toolbar on iPhone Duo
- On iPad, the edit panel now starts closed so it doesn't cover the document; the toolbar button opens it
- The iPad split view keeps the columns you chose after a trip through narrow Split View or Slide Over
- On iPad you can now refresh an open document from the toolbar, picking up a new version or changed details without closing and reopening it
