# Security policy

## Supported versions

Only the latest release on the App Store (and the current TestFlight beta) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/paulgessinger/swift-paperless/security/advisories/new).

Include what is affected, how to reproduce it, and the app version.
I aim to respond within a week, but this is a spare-time project, so it may take longer.
Once a fix is released, the advisory is published and you are credited unless you ask not to be.

## Scope

In scope: the iOS app, its share extension, and any server components in this repository.
Vulnerabilities in Paperless-ngx itself belong to the
[Paperless-ngx project](https://github.com/paperless-ngx/paperless-ngx/security).
